## Мова Java і платформа JVM

Мову Java створила компанія **Sun Microsystems** — команда під керівництвом **Джеймса Гослінга**. Робота почалася 1991 року (проєкт Green, мова спершу називалася Oak), а перша публічна версія **Java 1.0** вийшла **1996 року**. Девіз платформи — **«Write Once, Run Anywhere»**: один раз скомпільована програма має працювати на будь-якій системі, де є віртуальна машина Java.

У 2006–2007 роках Sun відкрила вихідний код платформи як проєкт **OpenJDK**. 2010 року Sun придбала компанія **Oracle**, яка відтоді керує розвитком мови. Сьогодні еталонна реалізація — це саме OpenJDK, а готові збірки JDK випускають кілька постачальників: Oracle, Eclipse Adoptium (Temurin), Amazon (Corretto), Microsoft, Azul (Zulu) тощо. Усі вони збираються з того самого коду й відрізняються переважно ліцензією та строком підтримки.

З 2017 року нова версія Java виходить **кожні пів року** — у березні та вересні. Кожна версія, що виходить раз на два роки, має статус **LTS** (Long-Term Support) і підтримується багато років: 8, 11, 17, 21, 25. Проміжні версії підтримуються лише до виходу наступної. Нові можливості мови часто спершу з'являються як **preview** (їх треба вмикати прапорцем `--enable-preview`), а через одну-дві версії стають остаточними. Зміни описують документи **JEP** (JDK Enhancement Proposal), перелік яких для кожної версії є на [openjdk.org](https://openjdk.org/projects/jdk/).

У цьому курсі ми використовуємо **Java 21** (LTS) як мінімальну версію. Окремо позначено можливості з новіших версій.

Java широко застосовується в серверних застосунках (Spring, Jakarta EE, Quarkus), обробці великих даних (Kafka, Spark, Hadoop, Elasticsearch), мобільних застосунках (Android), фінансових системах та інструментах розробника (IntelliJ IDEA, Gradle).

Мова **значно простіша** за C++: у ній немає вказівників, ручного керування пам'яттю, множинного наслідування класів, препроцесора та невизначеної поведінки в тому сенсі, як у C/C++. Синтаксис належить до родини C, тож знайомий кожному, хто писав на C чи C++.

### Основні риси мови

Java — **керована** (managed) мова: код виконується під контролем віртуальної машини **JVM**, а не безпосередньо операційною системою. Автоматичне керування пам'яттю (**Garbage Collector**) усуває цілі класи помилок, відомих з некерованих мов: витоки через забутий `free`, доступ до звільненої пам'яті, подвійне звільнення. Ціна — певні накладні витрати: збирач сміття іноді мусить призупинити програму, хоча сучасні збирачі (G1, ZGC) скорочують такі паузи до мілісекунд.

Це мова зі **статичною і строгою типізацією** та **об'єктно-орієнтована**. Типи всіх змінних відомі й перевіряються під час компіляції, тож багато помилок виявляються ще до запуску. Мова надає класи, інтерфейси, інкапсуляцію, наслідування і поліморфізм. На відміну від C++, у Java **немає глобальних функцій і змінних**: увесь код має бути всередині типів (класів, інтерфейсів, enum, records).

Водночас Java запозичує ідеї інших парадигм: функціональне програмування (лямбда-вирази, Stream API), декларативна обробка даних, а з Java 21 — легкі **віртуальні потоки**, які дозволяють писати простий блокувальний код, що масштабується як асинхронний.

### Як виконується код Java: байт-код і JIT

Щоб розробляти програми, потрібен **JDK** (Java Development Kit). Для запуску вже зібраної програми достатньо середовища виконання (JRE). Від Java 11 окремий JRE не розповсюджується, а для production збирають мінімальне середовище інструментом `jlink`.

| Компонент | Що містить |
| --- | --- |
| **JVM** | віртуальна машина: завантаження класів, перевірка байт-коду, інтерпретатор, JIT-компілятори, збирач сміття |
| **JRE** | JVM + стандартна бібліотека |
| **JDK** | JRE + компілятор `javac`, `jar`, `javadoc`, `jshell`, `jcmd`, `jlink` та інші інструменти |

Шлях від коду до виконання:

1. Компілятор **`javac`** перетворює вихідний код (`.java`) на **байт-код** — інструкції віртуальної машини — і записує його у файли `.class` (по одному на кожен клас).
2. Файли `.class` зазвичай пакують в архів **`.jar`**.
3. Під час запуску **JVM** завантажує класи, перевіряє байт-код (verifier) і починає його **інтерпретувати**. Методи, що виконуються часто («гарячі»), компілює в машинний код **JIT-компілятор** (Just-In-Time).

```text
   фаза компіляції                       фаза виконання
┌──────────────────┐   javac    ┌───────────────────┐  JVM: інтерпретація   ┌────────────────┐
│  Hello.java      │ ─────────► │  Hello.class      │ ────────────────────► │  машинний код  │
│  (вихідний код)  │            │  (байт-код)       │   + JIT (C1, C2)       │  процесора     │
└──────────────────┘            └───────────────────┘                        └────────────────┘
```

Віртуальна машина HotSpot має два JIT-компілятори: **C1** компілює швидко з простими оптимізаціями, **C2** витрачає більше часу, але генерує дуже оптимізований код на основі статистики виконання (які гілки найчастіші, які типи реально трапляються). Тому Java-програми потребують **розігріву** (warm-up): перші секунди роботи повільніші, ніж наступні.

Завдяки такій моделі той самий байт-код працює на Windows, Linux і macOS, на x86 і ARM. Байт-код можна переглянути інструментом `javap -c Hello.class`.

> [!NOTE]
> Існує й компіляція наперед (AOT): **GraalVM Native Image** перетворює застосунок на нативний виконуваний файл, який стартує за мілісекунди, але втрачає частину динамічних можливостей (див. розділ «Інше → JVM і збирання сміття»).

## Hello World

Найпростіша програма на Java — публічний клас, назва якого **збігається з назвою файлу**, з методом `main`:

```java
// Hello.java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

* `public class Hello` — клас, контейнер для даних і методів. Публічний клас мусить лежати у файлі `Hello.java`.
* `public static void main(String[] args)` — точка входу програми. `args` містить аргументи командного рядка.
* `System.out.println(...)` — виклик методу `println` на об'єкті `System.out` (стандартний вихід).

Компіляція і запуск:

```bash
javac Hello.java        # створює Hello.class
java Hello              # запускає клас Hello (без розширення .class!)
java Hello.java         # Java 11+: компіляція в пам'яті й запуск одним кроком
```

У Java 25 (JEP 512) для простих програм можна обійтися без явного класу і статичного методу (**compact source files** та **instance main methods**). Компілятор сам огорне код неявним класом:

```java
// Hello.java (Java 25+)
void main() {
    IO.println("Hello, World!");
}
```

У Java 22–24 це preview-можливість: `java --enable-preview --source 24 Hello.java`.

> [!TIP]
> Справжні проєкти не компілюють вручну командою `javac`: залежностями і збиранням керують Maven або Gradle (див. розділ «Інструменти»). Популярні IDE — **IntelliJ IDEA** (Community безкоштовна), **Eclipse**, **VS Code** з Extension Pack for Java. Для швидких експериментів у JDK є REPL **`jshell`**.

```text
$ jshell
jshell> var xs = List.of(3, 1, 2)
xs ==> [3, 1, 2]
jshell> xs.stream().sorted().toList()
$2 ==> [1, 2, 3]
jshell> /exit
```

## Базові інструменти

Щоб почати писати програми, варто познайомитися з кількома класами стандартної бібліотеки, які знадобляться одразу.

### Стандартне введення і виведення

Об'єкт `System.out` (типу `PrintStream`) друкує на стандартний вихід: `println` додає перенос рядка, `print` — ні, `printf` форматує за шаблоном. Помилки друкують у `System.err`.

Читати введення найпростіше класом `Scanner`:

```java
import java.time.Year;
import java.util.Scanner;

public class Greeting {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        System.out.print("Як тебе звати? ");
        String name = in.nextLine();
        int year = Year.now().getValue();
        System.out.printf("Привіт, %s! Зараз %d рік.%n", name, year);
        System.out.println("Привіт, " + name + "!");   // конкатенація
    }
}
```

`printf` і `String.format` використовують специфікатори формату: `%s` — рядок, `%d` — ціле число, `%.2f` — дробове з двома знаками, `%n` — перенос рядка, правильний для поточної системи. Від Java 15 можна писати `"Привіт, %s!".formatted(name)`.

> [!NOTE]
> У Java немає інтерполяції рядків на кшталт `"Привіт, {name}"`. Рядки збирають конкатенацією `+`, методами `format`/`formatted` або класом `StringBuilder`.

### Тип String

`String` — основний тип для роботи з текстом. Ключова властивість — **незмінність** (immutability): створений рядок змінити неможливо. Кожна операція, що нібито його змінює (дописування, заміна символів), насправді створює **новий** об'єкт.

```java
String txt = "Hello, ";
String txt2 = txt + "World!";             // "Hello, World!"

// txt2.charAt(5) = '?';                  // ПОМИЛКА: рядок не можна змінити
String txt3 = txt2.replace(',', '?');     // "Hello? World!"

String option = "first";
if (option.equals("first")) {             // вміст порівнюємо equals, а не ==
    System.out.println(txt2.toUpperCase());   // "HELLO, WORLD!"
}
```

> [!WARNING]
> Оператор `==` для рядків порівнює **посилання** (чи це той самий об'єкт), а не вміст. Два рядки з однаковим текстом можуть бути різними об'єктами, тож вміст завжди порівнюйте через `equals`. Детально — на сторінці «Рядки».

### Тип ArrayList

Один із найуживаніших контейнерів стандартної бібліотеки — `ArrayList<E>` з пакета `java.util`, динамічний масив (аналог `std::vector` з C++).

`ArrayList<E>` — це **узагальнений тип** (generic type): у кутових дужках вказують тип елементів, наприклад `ArrayList<String>`. Параметром типу може бути лише посилальний тип, тож для чисел використовують обгортки: `ArrayList<Integer>`, а не `ArrayList<int>`.

```java
import java.util.ArrayList;
import java.util.List;

List<Integer> numbers = new ArrayList<>(List.of(1, 2, 3, 4));

System.out.println("Кількість елементів: " + numbers.size());   // 4

numbers.add(5);                       // [1, 2, 3, 4, 5]
numbers.remove(Integer.valueOf(3));   // видаляє ЗНАЧЕННЯ 3 -> [1, 2, 4, 5]
numbers.remove(0);                    // видаляє елемент за ІНДЕКСОМ 0 -> [2, 4, 5]
numbers.set(1, 10);                   // [2, 10, 5]
int first = numbers.get(0);           // 2

List<Integer> copy = new ArrayList<>(numbers);   // копія списку

for (int n : numbers) {               // обхід елементів
    System.out.print(n + " ");
}
System.out.println();

numbers.clear();                      // []
```

Класи в Java мають **поля** (дані) і **методи** (поведінку). Окремої конструкції «властивостей» у мові немає: доступ до стану зазвичай відбувається через методи-гетери (`size()`, `get(i)`, `getName()`), а для незмінних даних — через records (розділ «Створення типів»).

> [!CAUTION]
> Для `List<Integer>` виклик `remove(3)` видаляє елемент **за індексом 3**, а не значення 3: перевантаження з параметром `int` має пріоритет перед автоупакуванням у `Integer`. Щоб видалити значення, пишіть `remove(Integer.valueOf(3))`.
